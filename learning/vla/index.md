# VLA 学习路线

## 当前学习目标

建议第一轮目标：用「把杯子拿起来」的例子，画出观察、指令、模型输出、执行与新观察的过程，并说明一条训练样本包含什么。开始学习时根据实际起点调整。

## 起点与学习路线

起点待诊断，尚无自测记录。以下是建议顺序，不代表已经学习。

| 顺序 | 学习问题 | 建议输出 |
| --- | --- | --- |
| 1 | 模型看到什么，输出的动作是什么？ | 一张流程图与具体输入输出例子 |
| 2 | 机器人演示怎样变成训练样本？ | 自己描述一个训练样本 |
| 3 | 动作 token 与连续动作块如何理解？ | 结合 OpenVLA 与 π0 解释差异 |
| 4 | 新论文改了系统的哪一部分？ | 分别从动作表示、架构、训练数据等维度定位改动 |

## 当前卡点与下次行动

尚未开始具体技术学习，卡点待确认。

下次从这个问题开始：「让机器人拿起杯子，你觉得模型应该接收什么，输出什么？」根据回答决定先补哪个基础概念。
